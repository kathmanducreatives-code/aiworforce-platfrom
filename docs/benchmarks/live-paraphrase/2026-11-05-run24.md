## The compiler-side failures: exact fields (from the recorded whole answers)

In every case the model's **understanding was correct**, and it also restated the same meaning as a free-form `hard_constraints` entry. Compiled a second time, each restatement became a hard requirement that no evidence can answer.

| Legacy field the model wrote | Rows | Example | Restates |
|---|---:|---|---|
| `signal` / `signals` / `required_signal` / `hiring` | 24 | `signal: "hiring"`, `signals: ["funding", "hiring AEs"]` | the understanding's signals |
| `employee_count` / `employee_range` | 11 | `between ["10", "100"]` | the stated `employee_range` |
| `hiring_role(s)` (excludes) | 7 | `"SDRs"` | the excluded role |
| `headquarters*` | 4 | `"North America"` | the place |
| `hiring_role` (includes), `role` | 2 | `"AEs"`, `"account_executive"` | the required role |
| `signal_recency_days` | 1 | `30` | the signal's own window |

Other compiler-side failures:
- **Generic company words became a hard industry:** `"businesses"`, `"US companies"` (M21, M23, M06). The understanding's industries were validated but never applied; industry criteria came from legacy `company_types`.
- **A hiring phrase became a role** (M23 "taking on more staff"). The understanding named no role.
- **The user's own "SDRs/BDRs" was refused as an actor reference** (M19). The `owner/name` guard matched the user's slash.

## Fixes (this PR)

All but F5 are **contract v3 only**; production runs v1. Each fix keeps the understanding authoritative.
- **F1:** a legacy hard constraint is skipped **only when every value restates an understanding item with the same polarity** (span, title, place, industry, signal kind/span).
  - Excluding a role the understanding requires is a contradiction, so it is kept.
  - Fields the compiler maps natively (`company_type`, `geography`, …) are never touched.
- **F2:** a size constraint is skipped only when every number equals the stated range's own bounds. **F2b:** a window constraint only when it equals a signal's own window.
- **F3:** verticals the understanding does not name, and that are not part of an understood industry, become **targets** (rank, never reject). Company Brain values keep their rules.
- **F4:** a hiring signal with no understood role is hiring for any role.
- **F5 (all contracts):** a string the user typed is never a forged actor reference. The guard still refuses one the user did not type.
