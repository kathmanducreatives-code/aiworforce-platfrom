# npm audit triage (2026-11-16): 48 findings, 1 critical

**Method:** read-only. `npm audit --json`, then `npm audit --omit=dev --json`. Each finding was traced (with `npm ls` and source imports) to whether it reaches **what is deployed**. Nothing was upgraded.

**What is deployed:**
1. **The frontend:** a static Vite bundle on Vercel (`dist/`: HTML, JS, CSS). There is no Node server, and `vercel.json` has rewrites and headers only.
2. **The backend:** Supabase Edge Functions on Deno. They import through `esm.sh` and `npm:` specifiers and **never read `node_modules` or `package-lock.json`**. The only npm-specifier import in an edge function that appears in this audit is `npm:zod@^3.25.76`.

So a finding matters for the deployed application only if the package ends up **in the browser bundle**, or a Deno function imports it.

## The critical finding: `proxy-addr` ≤ 2.0.7 (GHSA-jqcg-44mw-7w3h, IP spoofing via an IPv4-mapped IPv6 trust subnet)

- **Path:** `@lovable.dev/mcp-js@0.20.0` → `@modelcontextprotocol/sdk@1.28.0` → `express@5.2.1` → `proxy-addr@2.0.7`.
- **Where it is used:** `@lovable.dev/mcp-js` is a **Vite build plugin** (`mcpPlugin()` in `vite.config.ts`) plus tool definitions in `src/lib/mcp/`. Nothing in the app imports `src/lib/mcp`.
- **Deployed?** No. The production bundle contains no `express`, `proxy-addr` or `@modelcontextprotocol` code (checked in `dist/assets`). Vercel serves static files, and the production `mcp` edge function is Deno with its own imports.
- **Exploitable in production:** **No.**
- **Residual exposure:** only a local `vite dev` server, if `mcpPlugin` starts an express endpoint and that server is exposed beyond localhost.
- **Fix:** `@lovable.dev/mcp-js@3.5.0` is a **major** upgrade. Review it (or remove the plugin, if the Lovable MCP integration is no longer used now that hosting is on Vercel) before changing anything.

## Build-time and development only (not deployed)

These run on a developer machine or CI. They don't reach the bundle or the edge functions:
- **Build toolchain:** `vite` (dev-server file-serving advisories), `postcss`, `rollup`, `esbuild` (dev-server CORS), `source-map-js`, `browserslist`.
- **Path matching:** `glob`, `minimatch`, `picomatch`, `brace-expansion`.
- **Other build and test packages:** `nanoid` (build), `yaml`, `js-yaml`, `flatted`, `serialize-javascript`, `terser-webpack-plugin`, `ajv`, `@humanfs/node`, `baseline-browser-mapping`, `@tailwindcss/typography` / `postcss-selector-parser`.
- **The whole `@remotion/*` chain**, including `extract-zip` and `ws` (video tooling).

The **exposure** is a developer running `vite dev` on a network-reachable interface, or building untrusted input. **Advice:** keep the dev server on localhost, and take routine minor upgrades through a normal PR with the CI gates.

## Server libraries in `dependencies` that nothing deployed imports

- **Packages:** `@mendable/firecrawl-js` (with `axios`, `form-data`, `follow-redirects`), `@modelcontextprotocol/sdk` / `express` / `body-parser` / `qs` / `hono` / `@hono/node-server`, `fast-uri`, `ip-address`, `lodash`.
- **Not imported by deployed code:** `src/` doesn't import them. Edge functions don't import them via `npm:` or `esm.sh`; Firecrawl is called over HTTP from Deno code, not through this SDK.
- **Verdict:** not exploitable in the deployed app.
- **Cleanup:** consider moving them to `devDependencies` or removing them. That shrinks the audit surface without any runtime change.

## Recommended order (each a separate, reviewed PR; none applied)

1. `react-router-dom` → 6.30.6 (patch), with UI tests and the production build verifier.
2. Decide whether the Lovable MCP plugin is still needed. Remove it, or upgrade it to `@lovable.dev/mcp-js@3.5.0` (major). This clears the critical finding and the MCP SDK highs.
3. Move or remove unused server SDKs (`@mendable/firecrawl-js`, …) from `dependencies`.
4. `npm audit fix` without `--force` for the non-major transitive updates (build tooling), reviewed as one lockfile-only PR.
5. Plan the `zod` 4.x migration (frontend and the three edge-function `npm:zod` imports).
